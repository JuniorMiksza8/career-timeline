# Career Timeline

Narrative portfolio for José Junior Miksza, designed as a static site for GitHub Pages.

## Preview locally

Open `index.html` directly in a browser or start any static HTTP server in this directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content guidelines

Keep the narrative concise, factual, and focused on decisions, outcomes, and professional growth. Use only authorized media and public company information. Do not publish customer data, internal screenshots, proprietary diagrams, or employer-owned material without permission.

For new images, prefer WebP or AVIF, provide meaningful `alt` text, remove sensitive metadata, and optimize files for web delivery.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Place the contents of this folder at the repository root.
3. Push the default branch.
4. In **Settings → Pages**, deploy from the default branch and root folder.
5. Add the final public URL to the Open Graph metadata in `index.html`.

No build step or framework is required.
